# GeoWarp downloads

Change your iPhone's GPS location from your Windows PC.

**[Download the latest GeoWarp for Windows](https://github.com/kadenwprints/geowarp-releases/releases/latest/download/GeoWarp-Setup.exe)**

GeoWarp needs an active subscription. Get your license key at **https://geowarp.onrender.com**.

## Setup

1. Install **Apple Devices** from the Microsoft Store (or iTunes).
2. Run `GeoWarp-Setup.exe`. If Windows shows "Windows protected your PC", click **More info → Run anyway**.
3. Open GeoWarp, paste your license key, plug in your iPhone and click **Connect iPhone**.

To get your real location back, click **Reset**, quit GeoWarp, or restart your iPhone.
